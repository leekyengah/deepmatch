## Objective

## Method (to execute by Product lead)

1. **Recruit:** 6–12 participants (2–4 mỗi phân khúc), VN, 18+.
2. **Format:** 45-min semi-structured interview + optional concept walkthrough.
3. **Topics:** discovery privacy, mutual→chat trust, couple map value, breakup data fears, advisor comfort, admin trust.
4. **Artifacts required for Done:** interview notes (anonymized), segment table, insight backlog with evidence quotes, consent forms.
