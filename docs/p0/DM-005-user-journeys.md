# DM-005 — User Journeys (Zero → Value)

**Status:** In review  
**Dependencies:** DM-001, DM-004

## Journey 1 — Solo → Match → Chat

```
Register → Age/ToS consent → Mode=Solo → Progressive profile
→ Opt-in discovery → See ranked cards + reasons → Like/Pass
→ Mutual → Chat thread unlocked → Block/Report available
→ (Optional) Propose date → (Optional) Invite to Chúng mình
```

**Negative:** Underage denied; message without mutual denied; blocked user excluded.

## Journey 2 — Couple via invite (skip dating profile)

```
Register → Consent → Mode=Has partner → Create/Accept invite
→ Mutual accept → Pair space → Tabs: Map / Memories / Add / Promises / Us
→ First pin empty-state CTA → Add pin (layer) → Optional media
→ Private note default private → Explicit share/revoke
```

**Negative:** Expired/revoked invite; cross-pair read denied.

## Journey 3 — Chat → Pair transition

```
Mutual chat → Invite Chúng mình → Partner accepts separately
→ Pair created empty (no auto-import chat/journals)
```

## Journey 4 — Concierge

```
Pair/Solo opens Đồng hành → Browse services → Book → Consent grants
→ Advisor assigned → Notes scoped → Close case
```

## Journey 5 — Abuse → Admin

```
User reports → Moderator queue → Scoped evidence (if policy)
→ Action (warn/suspend) + audit → Appeal path
```
