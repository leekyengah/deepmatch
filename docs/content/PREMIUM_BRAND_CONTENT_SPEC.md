# Premium brand content spec (EXT-068)

Status: Draft for Founder/Product sign-off · Visual source: sheet 26 + REF-WEB/DATING/COUPLE · 2026-10-13

## Positioning

DeepMatch is a **premium relationship platform**: intentional discovery, private Couple Space (Sánh đôi), and optional Companion/Lifestyle — never “guaranteed soulmate” or emergency dispatch.

## Canonical journey labels (VI / EN)

| Journey | VI | EN |
|---|---|---|
| Discover | Tìm nhau / Khám phá (nav marketing) | Discover / Explore |
| Couple | **Sánh đôi** | Couple Space |
| Companion | Đồng hành | Companion |

Legacy UI “Chúng mình” must not appear on active screens.

## Hero (live)

- VI: «Gặp đúng người. Viết tiếp câu chuyện.»
- EN: «Meet the right person. Keep writing the story.»
- Support: connect from shared values; nurture depth — no fake social proof counts.

## Claim register (allowed)

- Mutual like opens chat only; Couple Space needs two-sided invite.
- Approximate location only; no background GPS.
- DEMO catalog / sandbox booking clearly labeled on staging.
- AI requires purpose consent; no clinical diagnosis / compatibility %.
- DeepSafe is not 24/7 emergency dispatch.

## Forbidden claims

- Fabricated partner logos, live inventory, verified counselors, testimonials from reference mock people.
- Exact GPS, private journal content, lock-screen chat text.
